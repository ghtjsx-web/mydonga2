---

선택한 파일 또는 폴더의 코드를 분석해서, 코드 초보자도 충분히 이해할수 있는 Mermaid구조도를 markdown 파일로 만들어 주세요

목표
-코드의 전체 흐름을 초보자도 이해할수 있게 구조도를 정리할것.
-너무 세부적인 코드 한줄 한줄이 아니라, 주요 흐름과 역할 중심으로 요약.
-결과물은 Markdown 파일로 저장.
-파일명은 원본 이름을 참고해서 '원본이름_structure.md' 파일 형식을 사용.
-한글설명및 영어설명 적절하게 혼합해서 가독성 있도록 작성.

검수
-Mermaid 코드 안에 특수문자 들어 갔는지 확인
-preview 미리보기에서 No diagram type detected 또는 Syntax error가 나지 않도록 단순한 문법으로 유지유지
